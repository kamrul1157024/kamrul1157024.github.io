Backprop, lesson by lesson

from one number to an N×M matrix — and why LoRA works
Lesson 1

One weight, one number

All of backpropagation is four local rules chained together. This is the smallest network that shows all four: y = w·x + b, loss L = (y − t)². Press Next ▸ and watch every single arithmetic step — forward to the loss, backward as each node hands a gradient to its inputs, then the update that nudges w and b downhill.

THE FOUR RULES — every backward pass ever written is these, chained: × multiply each input gets: upstream gradient × the OTHER input (∂s/∂w = x, ∂s/∂x = w) + add the upstream gradient copies to both inputs, unchanged (∂y/∂s = 1, ∂y/∂b = 1) − subtract +1 to the first input, −1 to the second (∂e/∂y = 1, ∂e/∂t = −1) ² square upstream gradient × 2·the input (∂L/∂e = 2e) chain rule: to reach an earlier node, multiply the local rules along the path — ∂L/∂w = 2e · 1 · x
Lesson 2

A neuron: many inputs, still one output

A neuron computes y = x₀w₀ + x₁w₁ + x₂w₂ + x₃w₃ + b — N lesson-1 multiplications sharing one sum. The rules don't change: each weight's gradient is still just upstream gradient × its own input. Watch the four product cells, then the four gradients.

DOT PRODUCT RULE y = Σᵢ xᵢ·wᵢ + b ∂L/∂wᵢ = ∂L/∂y · xᵢ ∂L/∂xᵢ = ∂L/∂y · wᵢ ∂L/∂b = ∂L/∂y wᵢ appears in exactly one product, so its gradient touches exactly one input: xᵢ. Note also what the update can't do: many different w give y = t — gradient descent walks to the one nearest the starting point. Remember this under-determination; lesson 4 is built on it.
Lesson 3

The matrix: B samples, M outputs

Tile lesson 2 over B=8 samples and M=3 outputs and the dot products pack into a matrix product Y = X·W + b. Same rules — the only new idea is shape bookkeeping: the transpose appears exactly where dimensions need to line up. Step through epochs, watch the loss curve, and hover any cell to see its exact arithmetic.

THE MATRIX RULES — lesson 1's rules with transposes to make shapes fit: ∂L/∂W = Xᵀ · G (N×B)(B×M) → N×M gradient w.r.t. a factor = upstream gradient × the OTHER ∂L/∂X = G · Wᵀ (B×M)(M×N) → B×N factor, transposed so inner dimensions cancel ∂L/∂b = Σ_b G b is added to every row, so it collects every row's gradient element-wise: ∂L/∂W[i,j] = Σ_b X[b,i]·G[b,j] = (col i of X) · (col j of G) — the multiplication rule of lesson 1, summed over the batch. Each weight listens to exactly one input feature and one output error.
Lesson 4

Fine-tuning: full vs LoRA

Fine-tuning is lesson 3 with a constraint. Full fine-tuning moves every entry of W. LoRA freezes W and learns a rank-r update A·B instead — the same gradient XᵀG exists, but only its projections through the bottleneck are ever applied. Flip between the modes; both start from the identical W, so the loss curves are a fair race.

WHY LORA WORKS full: W ← W − η·XᵀG trains N·M parameters directly lora: A ← A − η·(XᵀG)·Bᵀ trains r·(N+M) — the update ΔW = A·B can only ever be rank ≤ r, B ← B − η·Aᵀ·(XᵀG) but pretrained models usually need only low-rank corrections The price: if the needed update isn't low-rank, LoRA plateaus where full fine-tuning would keep going. The payoff: a fraction of the parameters, one frozen base model, many swappable adapters.
Backpropagation is four local rules — multiply, add, subtract, square — chained over a computation graph. Scalars make the rules visible; matrices only add bookkeeping. LoRA is the same chain with a rank constraint on where the gradient is allowed to act.
