Backprop from scratch

animated lessons: the four rules → vectors → matrices → LoRA
Lessons
Slide 1

Local rule №1: multiply

Zoom into one gate: s = w·x. A gradient g arrives at s from the right ("L changes this much when s changes"). The gate hands it backward to both inputs — but each one scaled by the other input. Press Animate backward ▸.

MULTIPLY RULE s = w·x ∂s/∂w = x ∂s/∂x = w ∂L/∂w = g · x ← w's gradient is the upstream gradient, scaled by the OTHER input ∂L/∂x = g · w why: nudge w by ε and s moves by x·ε — the gate amplifies w's influence by exactly x.
Slide 2

Local rule №2: addition is distribution

The gate y = s + b does nothing to the gradient at all — it photocopies it. One gradient g arrives at y; two identical copies leave, one down each input branch. Watch it split.

ADD RULE — GRADIENT DISTRIBUTES y = s + b ∂y/∂s = 1 ∂y/∂b = 1 ∂L/∂s = g ∂L/∂b = g ← the upstream gradient COPIES to every input, unchanged and the mirror image: when one value feeds N different places, its total gradient is the SUM of all N copies coming back. Distribution forward, summation backward. (Slide 7 uses this.)
Slide 3

Two more rules: subtract and square

The last two gates of the graph. Subtract (e = y − t) is add's sibling: the gradient copies to the first input and copies negated to the second. Square (L = e²) scales the incoming gradient by 2e — the only other gate that changes it. Press Animate ▸: square first (it feeds the subtract gate), then subtract.

L = e²
e = y − t
SUBTRACT RULE e = y − t ∂e/∂y = 1 ∂e/∂t = −1 → ∂L/∂y = g, ∂L/∂t = −g SQUARE RULE L = e² ∂L/∂e = 2e → incoming g leaves as g·2e four gates, four rules: multiply scales by the other input, add copies, subtract copies with a sign, square scales by 2·input. That is the entire vocabulary of backprop.
Slide 4

The chain: every gate does its one rule

All four rules, one graph: y = w·x + b, loss L = (y − t)². Move the sliders and run it forward — then watch it run backward: the square gate scales the gradient, the subtract gate signs it, the add gate copies it, the multiply gate scales it again. What arrives at w is the chain rule — one multiplication per gate on the path.

CHAIN RULE — the gradient at w is the product of the local rules along the path: ∂L/∂w = 2e (square) · 1 (subtract) · 1 (add) · x (multiply) nothing else exists. Every backprop in every framework is these local rules, composed.
Slide 5

The formula morphs: one weight → a vector of weights

A neuron has four inputs and four weights: y = x₀w₀ + x₁w₁ + x₂w₂ + x₃w₃ + b. Press Morph ▸ and watch the multiply rule from slide 2 change shape — spoiler: it doesn't. Only the subscripts do.

DOT PRODUCT RULE y = Σᵢ xᵢ·wᵢ + b ∂L/∂wᵢ = g · xᵢ ∂L/∂b = g wᵢ appears in exactly one product, so its gradient touches exactly one input: xᵢ. The add gates distribute g to every product; each multiply gate scales it by its own xᵢ.
Slide 6

The formula morphs again: vectors → matrices

Now B=8 samples and M=3 outputs at once: Y = X·W + b. The gradient formula must morph too — press Morph ▸. The interesting moment: the product only fits together one way, and that's where the transpose comes from. It's not a new rule — it's the multiply rule with shapes that line up.

THE MATRIX RULES ∂L/∂W = Xᵀ · G (N×B)(B×M) → N×M gradient w.r.t. a factor = upstream gradient × the OTHER ∂L/∂X = G · Wᵀ (B×M)(M×N) → B×N factor, transposed so inner dimensions cancel element-wise: ∂L/∂W[i,j] = Σ_b X[b,i]·G[b,j] = (col i of X) · (col j of G) — lesson 2's multiply rule, summed over the batch.
Slide 7

Distribution in reverse — and LoRA

The bias b is added to all 8 rows of Y. Slide 3 said a value used in N places collects N gradient copies that sum — so ∂L/∂b = Σ_b G. Press Animate ▸ to watch 8 copies converge into one. Then the same chain with a constraint: LoRA freezes W and learns a rank-r update A·B instead.

WHY LORA WORKS full: W ← W − η·XᵀG trains N·M parameters directly lora: A ← A − η·(XᵀG)·Bᵀ trains r·(N+M) — the update ΔW = A·B can only ever be rank ≤ r, B ← B − η·Aᵀ·(XᵀG) but pretrained models usually need only low-rank corrections The price: if the needed update isn't low-rank, LoRA plateaus where full fine-tuning would keep going. The payoff: a fraction of the parameters, one frozen base model, many swappable adapters.
Backpropagation is four local rules — multiply, add, subtract, square — chained over a computation graph. Addition distributes the gradient; multiplication scales it by the other input; matrices only add shape bookkeeping. LoRA is the same chain with a rank constraint on where it may act.
